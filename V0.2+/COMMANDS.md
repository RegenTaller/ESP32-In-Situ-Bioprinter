# Команды прошивки v0.2 (COM-порт и Bluetooth)

Команды одинаково работают через USB-COM (115200 бод по умолчанию) и Bluetooth (`InSitu-Bioprinter`).
Ответы и телеметрия приходят в оба канала.

## Формат

| Правило | Пример |
|---|---|
| `имяЗНАЧЕНИЕ` — как в v0.1 | `kp0.5`, `tposMMS10`, `Z-0.2` |
| Также `имя ЗНАЧЕНИЕ` и `имя=ЗНАЧЕНИЕ` | `kp 0.5`, `kp=0.5` |
| Несколько команд в строке — через `;` | `speed40; height0.34; save` |
| Имя без значения выводит текущее значение | `kp` → `kp=0.4 pwm/tick` |
| Регистр имени не важен | `POS` = `pos` |
| Дробные значения принимаются везде | `height0.34`, `sh12.5`, `Z0.05` |
| Строка заканчивается `\n`/`\r` или паузой 50 мс | терминал без перевода строки тоже работает |

Имя команды — это ведущие буквы, и сравнивается оно **целиком**. В v0.1 команды искались подстрокой, поэтому
`speed40` срабатывал ещё и как `sp` (скорость главного привода падала до 1 мм/с), а `height0.34` превращался в 0.

Каждая принятая строка повторяется эхом: `> строка`. Ответы:

- `OK ...` — команда выполнена;
- `ERR ...` — команда отклонена, причина указана;
- `FAULT ...` / `STOP ...` — авария (см. раздел «Аварии»);
- `EVT ...` — событие (перемещение завершено и т. п.);
- `WARN ...` — предупреждение.

## Порядок запуска

1. После включения **слежение выключено**, моторы удерживают позицию. В v0.1 головка начинала следить сразу после подачи питания.
2. Если при старте выведено `Z: NOT homed`, задайте позицию головки:
   - подведите головку в верхнее положение командой `zjog-5` (повторять; без хоминга скорость 5 мм/с и пределы отключены), затем `zhome`; либо
   - `zset<мм>`, если позиция известна; либо
   - `zhomehard` — движение вверх об упор на пониженном токе (см. ниже).
3. Проверьте датчик: `status` (строка `sensor: ... fresh=1`) или телеметрию `Head1`.
4. Задайте отступ `sh`, параметры печати и при необходимости `save`.
5. `track1` — слежение, `track0` — выключить. `stop` или `!` — немедленная остановка всего.
6. Подача: `ext1` (непрерывно со скоростью печати) и `ext0`, или перемещения `Z…`, `tposMMS…`.

## Система

| Команда | Действие |
|---|---|
| `help`, `?` | краткий список команд |
| `status` | полное состояние: аварии, ось Z, датчик, дозатор, параметры |
| `ver` | версия прошивки и дата сборки |
| `stop`, `!` | аварийная остановка: шаги прекращаются сразу, ДПТ на тормоз. Сброс — `clear` |
| `clear` | сброс всех аварий. Слежение после сброса выключено |
| `save` | сохранить параметры в энергонезависимую память (NVS). Только в покое обеих осей |
| `load` | загрузить параметры из NVS |
| `defaults` | заводские параметры (в RAM; `save` — чтобы сохранить) |
| `reboot` | перезагрузка контроллера |
| `COM<бод>` | скорость COM-порта: 1200 … 921600 (из списка стандартных). Применяется сразу; `save` — сохранить |

## Телеметрия

| Команда | По умолч. | Действие |
|---|---|---|
| `PD` [0/1] | 1 | общий выключатель вывода данных |
| `period<мс>` | 100 | период вывода, 10–60000 мс |
| `millis` [0/1] | 0 | добавлять время (мс) вторым полем |
| `POS` [0/1] | 0 | позиции толкателя |
| `VELS` [0/1] | 0 | скорости толкателя |
| `Head` [0/1] | 0 | датчик и ось Z |
| `PWM` [0/1] | 0 | выходы ПИД дозатора (новое) |

Без значения команды переключают флаг, как в v0.1; с `0`/`1` — устанавливают явно.

Формат строк: в начале строки стоит метка. В v0.1 меток не было, поэтому скрипты обработки нужно поправить: пропускать первое поле.

```
POS,[мс,]опора_тик,энкодер1_тик,энкодер2_тик,цель_тик
VEL,[мс,]опорная_скорость,скорость1,скорость2        (тик/с)
HEAD,[мс,]дистанция_сырая_мм,дистанция_фильтр_мм,цель_Z_мм,позиция_Z_мм,достоверность(0/1)
PWM,[мс,]ШИМ1,ШИМ2,интеграл1,интеграл2
```

## Главный привод (ось Z головки)

Позиция 0 мм — верхнее, отведённое от поверхности положение; «+» — вниз, к поверхности.

### Действия

| Команда | Действие |
|---|---|
| `track1` / `track0` | включить / выключить слежение. Требует: позиция Z известна, нет аварий, датчик даёт достоверные отсчёты |
| `retract` | отвести головку в 0 мм |
| `zgo<мм>` | перейти в абсолютную позицию (0…zmax). Только при выключенном слежении |
| `zjog<мм>` | относительное перемещение. Без известной позиции — 5 мм/с, пределы отключены (для ручного хоминга) |
| `zhome` | считать текущую позицию нулём (головка вручную подведена вверх) |
| `zset<мм>` | считать текущую позицию равной заданной |
| `zhomehard` | хоминг об верхний упор: вверх на zmax+10 мм со скоростью 5 мм/с при 70 % тока, затем позиция = 0. Сначала убедитесь через `zjog`, что на пониженном токе головка поднимается |

### Параметры

| Команда | По умолч. | Диапазон | Описание |
|---|---|---|---|
| `sp` | 20 | 1–150 мм/с | предел скорости. В v0.1 реальная скорость была вдвое выше заданной; теперь `sp20` = 20 мм/с |
| `za` | 1000 | 10–5000 мм/с² | предел ускорения (в v0.1 разгона не было) |
| `zkp` | 15 | 1–100 1/с | коэффициент контура положения |
| `zdb` | 0,05 | 0–2 мм | зона нечувствительности |
| `zff` | 0,5 | 0–1,5 | доля упреждения по скорости поверхности (0 — выкл.) |
| `sh` | 0 | 0–200 мм | отступ: цель = дистанция − sh (как в v0.1), теперь дробный |
| `zmax` | 82 | 1–300 мм | программный предел хода. **Задайте по реальной механике** |
| `zmmrev` | 31,4159 | 5–200 мм/об | ход на оборот шестерни π·m·z. В v0.1 — опечатка 31,141592 (−0,9 %) |
| `zcur` | 200 | 50–1200 мА | ток TMC2130 (RMS) |
| `zstealth` | 1 | 0/1 | режим stealthChop |
| `zdir` | 0 | 0/1 | инверсия направления |

## Датчик дистанции (HC-SR04)

| Команда | По умолч. | Диапазон | Описание |
|---|---|---|---|
| `sos` | 343 | 300–360 м/с | скорость звука (в v0.1 — 335) |
| `uscal` | 1 | 0,5–1,5 | калибровочный множитель |
| `usoff` | 0 | −100…100 мм | калибровочное смещение |
| `usmin` | 20 | 2–200 мм | минимум достоверной дистанции (HC-SR04 ненадёжен ближе 2 см) |
| `usmax` | 400 | 20–5000 мм | максимум достоверной дистанции; «нет эха» даёт ~6 м и отбрасывается |
| `ustrack` | 82 | 5–500 мм | дальше этой дистанции слежение не опускает головку (как ограничение 82 мм в v0.1) |
| `usjump` | 15 | 0,5–500 мм | одиночный скачок больше этого отбрасывается; два согласованных подряд принимаются |
| `usper` | 10 | 10–200 мс | период запуска датчика |
| `ustimeout` | 100 | 20–5000 мс | нет достоверных отсчётов дольше — авария `SENSOR` при слежении |
| `fa` | 0,25 | 0,01–1 | α-β фильтр: α (меньше — сильнее сглаживание, больше задержка) |
| `fb` | 0,01 | 0–1 | α-β фильтр: β (оценка скорости поверхности) |

Фильтр Калмана из v0.1 заменён α-β фильтром. У прежнего фильтра коэффициент усиления почти обнулялся, когда поверхность двигалась медленно, отсюда задержка около 400 мс.

## Дозатор: перемещения

| Команда | Действие |
|---|---|
| `tpos<тик>` | абсолютная цель в отсчётах энкодера |
| `tposMMS<мм>` | абсолютная цель в мм хода штока |
| `tposob<об>` | абсолютная цель в оборотах винта |
| `Z<мм>` | сдвиг цели на мм (относительно текущей цели) |
| `Zob<об>` | сдвиг цели на обороты винта |
| `Ztick<тик>` | сдвиг цели в отсчётах энкодера |
| `ext1` / `ext-1` / `ext0` | непрерывная подача вперёд / назад до `dmax`/`dmin` / плавная остановка (новое) |
| `dzero` | считать текущую позицию толкателя нулём (новое) |
| `Savepos` | сохранить позиции сейчас (в v0.2 они и так сохраняются через 1 с покоя) |

Цели вне `dmin…dmax` отклоняются. Пределы отсчитываются от нуля толкателя (`dzero`).

| `jamt` | 1000 | 50–60000 мс | время в пределе `emax` до аварии `JAM` (новое) |
| `relief` | 100 | 0–20000 тик | отвод толкателя после заклинивания — сброс давления (новое) |
| `dlead` | 1 | 0,1–20 мм | ход винта |
| `dmin` / `dmax` | −60 / 60 | −500…500 мм | программные пределы хода толкателя |

Коэффициенты ПИД из v0.1 в v0.2 переносить нельзя: изменились структура регулятора и единицы. Значения по умолчанию
подобраны по модели мотора и требуют настройки на стенде (см. README.md).

`rk` и `rconst` удалены. На скорости печати оба метода «редукции ШИМ» поднимали ШИМ до `minDuty` и разгоняли толкатель.
Их задачу выполняют `emax` (ограничение выброса) и `jamt` (детектор заклинивания).

## Параметры печати

| Команда | По умолч. | Диапазон | Описание |
|---|---|---|---|
| `speed` | 40 | 0,1–500 мм/с | скорость печати |
| `height` | 0,34 | 0,01–10 мм | высота слоя |
| `width` | 0,4 | 0,01–20 мм | ширина линии |
| `diameter` | 14,85 | 1–60 мм | внутренний диаметр шприца |

Любая из этих команд пересчитывает `vel` = ширина × высота × скорость / (π·d²/4). Ответ показывает скорость штока и расход в мкл/с.

## Аварии

Аварии защёлкиваются: пока не отправлен `clear`, команды движения отклоняются.

| Авария | Причина | Реакция |
|---|---|---|
| `SENSOR` | при слежении нет достоверной дистанции дольше `ustimeout` (обрыв, нет эха, вне `usmin…usmax`) | слежение выкл., головка отводится в 0 мм, подача плавно останавливается |
| `JAM` | толкатель отстаёт от опоры на `emax` дольше `jamt` (окклюзия, заклинивание) | подача остановлена, толкатель отводится на `relief` |
| `SKEW` | энкодеры двух моторов разошлись больше `skew` | оба ДПТ на тормоз. Проверить механику, затем `dzero` и `clear` |
| `STOP` | команда `stop` / `!` | все шаги прекращены, ДПТ на тормоз |
| `WDT` | контур управления не выполнялся дольше 50 мс | прерывание таймера само останавливает шаги и тормозит ДПТ |

Предупреждения: `WARN track: surface closer than sh` — поверхность ближе отступа, головка упёрлась в верхний предел;
`WARN sensor: distance jump confirmed` — дистанция скачком изменилась, фильтр перезапущен.
